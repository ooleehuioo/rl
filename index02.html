设计特点

这个导航栏还原了 Apple 官网的核心体验：深色半透明背景配合 backdrop-filter 毛玻璃模糊效果， 滚动时导航栏始终固定在页面顶部。鼠标悬停时会显示下拉菜单， 移动端则自动切换为汉堡菜单 + 侧滑面板。

核心功能

✓ 粘性定位（Sticky）—— 始终在屏幕顶部
✓ 毛玻璃模糊效果（backdrop-filter blur）
✓ 桌面端下拉菜单（hover 触发）
✓ 搜索栏弹出面板
✓ 移动端汉堡菜单 + 侧滑面板
✓ 完整的响应式适配
✓ 无依赖纯 HTML + CSS + 少量 JS
